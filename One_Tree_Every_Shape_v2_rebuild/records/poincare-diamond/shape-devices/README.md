# Each shape as its own measuring device (Jeromie Beasley, 22 Nov 2026, AI-assisted)

A shape is a set of flat faces; a point carries one book per face (its gap to that face). Reading = the shape's own
distance (Hilbert's rule, the rule that gives the ball its Klein / physical map). Script SHAPE-DEVICES-01.

- H0: face-book reading = the shape's own cross-ratio distance, for triangle, square, pentagon, hexagon, tetrahedron, cube, octahedron, dodecahedron, icosahedron (worst 3e-15).
- H1: two faces (a line) give the peel step, coordinate = tanh of distance (4e-16).
- H2/H3: triangle and tetrahedron are exactly flat: midline = half to 12 digits, any book move reads the same from anywhere (1e-13). Disk and ball bend one way (midline < half).
- H4/H5 (fork): square and cube's own reading is NOT unchanged by per-axis peel moves (changes up to 1.27 / 1.49); the diamond's per-edge reading is. Own reading runs 0.5 to 1 times the diamond's per-edge sum.
- A first midline run using straight chords was invalid (it made the flat triangle look bent); the other polytopes are not classified by these tests.
Prior art: Hilbert geometry; flat only for the simplex (de la Harpe; Foertsch and Karlsson), Riemannian only for the ellipsoid. Untested against a measurement.

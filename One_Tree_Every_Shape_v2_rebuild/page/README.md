# One Tree, Every Shape v1 - Jeromie Beasley, 23 Nov 2026 (built with AI assistance)

The better version of One Tree, One Ball (Seiberg-Witten 4): no ball. Every eye is drawn inside the chosen solid
(tetrahedron, cube, octahedron, dodecahedron, icosahedron): each point of the tree is carried along its own ray and
stretched so the old rim lands on the solid's faces. Face Smith charts are the solid's skin.

Eyes: 1 ride the chain, 2 the whole chain (with the shape's own distance reading), 3 Seiberg-Witten charge chains,
4 harmonic winding (all as in the original), 5 the wall line for the loop (Two Trees v3: tr = 2 - 4 sinh^4(r/2);
cos = -527/625 and fixed point (3,2,2,0) at z = 5, checked on 4x4 boosts), 6 a Smith chart on every face
(keeps angles / stretched; impedance, admittance flip, both). Global: shape, partner shape (alternate reader), face charts.
build.py makes the page from the original file (kept unchanged); new_eyes.js holds the additions; shot.js is the render check (no page errors).
